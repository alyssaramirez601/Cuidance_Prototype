# Result names

The name is the first thing someone sees when the result pops up. It should feel warm, say what the result is about in one glance, and never label the person. Every main quiz path has a name below, in the same style as wireframe 06. Above every name the result card shows the eyebrow **YOUR GUIDANCE**.

These names are our call (Evidence: Assumption), not research. In testing, ask testers what they think the result is about from the name alone, and whether it feels like it is about them or about a label.

## Anatomy

1. **Headline:** a warm approach, then an easy payoff. Example: "Calm hydration, less guesswork" ("Calm hydration" is the approach, "less guesswork" is how it should feel). Under 32 characters.
2. **Subtitle:** what is inside, in plain words. Up to three focus points from "Start here," ending with how big the routine is. Under 85 characters. Example: "Light moisture, fragrance-free picks, and a short routine you can build on."
3. **Never a label for the person.** No skin types, hair types or problems in the name. The answers stay in the "You selected" chips below it.

## Six naming rules

| Rule | Yes | No |
| --- | --- | --- |
| Name the approach, never the person | Light layers, still hydrated | Oily skin fix |
| Promise ease, not a new face | Smoother days, less fuss | Flawless frizz-free hair |
| Soft promises only | Shade matching, less guesswork | Your perfect match |
| Works at every skin tone and texture | Your texture, front and center | Brighter, lighter skin |
| Cute only if it reads in one glance | Wash day, made easier | Suds-tastic shampoo saga |
| Short enough for the result card | Headline under 32 characters, subtitle under 85 | Names that wrap to 4 lines |

**Words that never go in a name:** fix, flawless, perfect, anti-, problem, best, guaranteed, slimming, brightening or whitening (unless chosen).

## How the app picks a name (one name per result, chosen in this order)

The name never changes the advice. It only labels what is already in the result.

1. **Sensitivity first.** If someone picks "Very sensitive," the gentle name leads, because comfort comes before everything else.
2. **Then the first area.** Otherwise the first area in a fixed order names it: skin, hair, makeup, body care, products. A fixed order means no hidden ranking.
3. **Other areas join the subtitle.** With two areas, the second one shows up in the subtitle so nothing they picked disappears.
4. **Three or more: an umbrella.** With three or more areas, an umbrella name covers everything, and each area gets its own tab.
