# How results are delivered

Same advice, shown the way each person asked. Three of the "Getting started" answers never change what Cuidance suggests. They only change how the result is shown.

- **U2 (What would you like to do today?)** changes the **order**: which part of the result comes first.
- **U3 (How confident do you feel...?)** sets the **starting depth**: how long and detailed the first view is. Anyone can expand or shorten it.
- **U4 (How can Cuidance support you?)** changes the **layout**: compact, compared, explained.

All of these are Evidence: Assumption (our design call, to be tested).

## U2 · Changes the order

| Answer | How the result changes |
| --- | --- |
| Learn more about my needs | Put the "what your selections suggest" explanation first. Use a short concept, then example, then limitation sequence. Do not create a diagnosis or infer a new attribute. |
| Find products to explore | Put the existing product-type guidance first. Use cards titled "Purpose," "Why it may fit," and "What to check." No new recommendations generated by the "what to do today" question. |
| Understand a product or ingredient | Put the ingredient or label explanation first, followed by relevance and limits. Define the first unfamiliar term inline. |
| Compare a few options | Present the same guidance in aligned comparison rows. Keep criteria consistent and unknown information visible. |
| I'm not sure yet | Show the uncertainty follow-up, then one short starting explanation with optional expansion. No guessed goal. |

## U3 · Sets the starting depth

| Answer | How the result changes |
| --- | --- |
| 1 · Not confident yet | About 80 to 120 words in the overview; up to three brief focus points; define essential terms; prominent optional "Why?" expansions. Warm but not patronizing. |
| 2 · A little confident | About 100 to 150 words; short examples; one layer of optional detail per focus point. |
| 3 · Somewhat confident | About 120 to 180 words; concise reasons plus optional ingredient-role details and comparisons. |
| 4 · Mostly confident | About 150 to 220 words; make tradeoffs, evidence limitations, and ingredient-role details easier to expand. Retain plain language. |
| 5 · Very confident | About 180 to 250 words; offer deeper evidence and formulation explanations, original label names, and source access. Do not automatically add steps or remove definitions. |

## U4 · Changes the layout

| Answer | How the result changes |
| --- | --- |
| Keep things simple | Short overview, compact focus points, optional expansions. Do not suppress essential cautions or change the underlying recommendation. |
| Explain unfamiliar terms | Define terms at first use; preserve original ingredient names in an expandable label view. |
| Explain why something may fit | Show one selection, then reason, then limitation sentence under each focus point. |
| Help me compare options | Use aligned criteria or a short comparison list; avoid an automatic winner. |
| Help me understand ingredients | Expand ingredient roles already relevant to the modules; do not add ingredient recommendations simply to fill the view. |
| Include products I already use | Display already-supplied products beside relevant guidance. If details are missing, provide an optional input field; do not invent compatibility. |
| Give me space to explore | Neutral option wording, no default purchase action, no urgency language, and expandable alternatives. |
| Something else | Optional free text describing a presentation preference. Preserve the existing content until the request is understood. |

## Six tie-breaker rules

If two of these answers seem to ask for different things, the result follows these rules in order.

1. Safety notes and real uncertainty always stay visible.
2. "Keep things simple" sets the short default view, even at confidence 5.
3. Ingredient and evidence detail stays available by expanding.
4. "Explain unfamiliar terms" works at every confidence level.
5. The "what to do today" answer sets the order, the confidence answer sets the starting depth, and the support answer sets the layout.
6. Free text never overrides the safety boundaries.

Plain language for everyone. Confidence is not a stand-in for literacy or expertise. Anyone can expand or shorten the view.

## Result template: every result uses the same 8 sections, in this order

The "what to do today" answer moves sections up or down. The confidence and support answers change their length and layout. The sections themselves stay the same.

1. **Your exploration today:** One or two sentences naming the selected topics and goals without assigning attributes.
2. **Start here:** Up to three deduplicated focus points across the whole result, not three per branch.
3. **Why these may fit:** The revised "why" lines after combination and cross-branch rules are applied.
4. **Explore by care area:** Separate expandable hair, skin, makeup, body, and product-information sections.
5. **Products or ingredients in context:** Relevant ingredient roles, actual supplied products, or comparisons; distinguish label claims from independent evidence.
6. **What to check:** Relevant tolerance, use-area, treatment, and removal notes. Essential cautions also appear beside the affected suggestion.
7. **What remains open:** Unanswered details, assumptions, and conditional guidance.
8. **Evidence and sources:** A strength label and linked source for each material claim, including inside expanded content.

## Bigger results: when someone picks 3 or more care areas

One result, not five reports stacked on top of each other.

- **One shared overview:** No more than three opening focus points across the whole result.
- **Tabs or accordions:** One per care area. Do not stack five full reports.
- **Merge shared guidance:** For example, fragrance-label education appears once.
- **Keep area rules separate:** Facial sensitivity does not mean underarm sensitivity; eye-only rules stay with eyes.
- **Neutral order:** If no priority is known, use a fixed order, not a hidden ranking.
- **Nothing hidden:** "Show fewer at once" never means dropping matched guidance.
